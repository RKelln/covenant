# Outreach Materials

Canonical source documents for outreach — artist statements, project descriptions, promotional copy, and boilerplate that applications draw from.

These are reference documents. When preparing a specific application or submission, copy the relevant content and edit it for context. The originals here remain authoritative and will evolve with the project independently of any submission that has already used them.

## Contents

- `covenant_one_page_brief.md` — one-page external overview for email attachments and general outreach
- `promo_lines.md` — short promotional descriptions and taglines

## Wordmark and Brand Assets

The canonical Covenant logo assets live in `assets/`, not in `outreach/materials/`. That keeps a single source of truth for the mark and makes it easier to reuse across the website, PDFs, slides, and outreach documents.

- `assets/covenant_logo.png` — combined Covenant wordmark (mark + logotype); use this for briefs, decks, and general outreach
- `assets/covenant_mark.svg` — standalone Covenant mark; use this when only the symbol is needed

For outreach documents, reference these files directly from their source markdown rather than copying them into local folders. Only create outreach-specific derivatives if you genuinely need a cropped or format-specific variant.
